Introduction to Machine Learning in Python  

24 & 25 February, 9:00am-5:00pm:
in-person only

Building machine learning models sounds useful, but how do you get started? The amount of information available can be overwhelming, and choosing a model and workflow for your particular needs can be a nightmare. In this workshop we will take you through the process and illustrate different kinds of models, what they are useful for, and how to get the best out of them.
We will use Python data science tools and scikit-learn machine learning library to give you a hands-on introduction to machine learning analyses. We will build, evaluate, compare, and tune predictive models. Along the way, we’ll learn about key concepts in machine learning including overfitting, resampling, and feature engineering.
You will gain knowledge about good predictive modelling practices, as well as hands-on experience in applying them. This workshop assumes that you can import data into Python, select and manipulate pandas dataframes, and make basic plots with matplotlib. We expect participants to have some exposure to basic statistical concepts, but NOT intermediate or expert familiarity with modelling or machine learning.

Have you done an experiment and are not sure where to start with your data analysis? Is the data confusing and full of problems that you’re not quite sure how to solve?
Never fear, come along to our Exploratory Data Analysis in R workshop and we will walk you through how to get started with your data analysis and fix some of the pesky problems that plague you!

Demystifying statistical modelling 

19 March Hybrid workshop: in-person or Zoom

Do you get confused about the differences between linear and logistic regression or ANOVA, ANCOVA, repeated measures and mixed models? On 19 March we will deliver three workshops from our modular statistical training system to demystify these terms and show how all of these align in the one Linear Models framework.
Linear Models Module 1 explains how the common analyses of regression, ANOVA, ANCOVA and repeated measures can all be done using the same Linear Models workflow. Module 2 then extends this to the Generalised Linear Model (GLM) framework for non-normal distributions such as Logistic and Count/Poisson regression. Aligning all these different methods into the same box with the same generic workflow makes it much easier to understand and remember how to apply them, while the practical examples provided give clear instructions for later use. The final module on the day, Statistical Model Building, explores the issues around more complex statistical modelling to build multivariable models with many predictors.
