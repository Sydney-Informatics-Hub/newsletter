SIH Masterclass: Getting started with Git in RStudio: a hands-on guide 

27 April, 3-4:30pm, online and in-person

This Masterclass is an opportunity for the attendees to bring their own laptop and R project and learn how to use Git and RStudio together for version control and collaboration. We will provide hands-on assistance in getting Git and RStudio to communicate effectively.
The Masterclass will highlight the importance of making collaboration transparent for everyone, as well as the benefits of using version control to maintain a clear and comprehensive record of project development. We will provide the attendees with the tools and knowledge they need to collaborate more efficiently and keep their projects organized and reproducible.

Introduction to Machine Learning in Python  

2 & 3 May, 9am-5pm, in-person only

This workshop introduces machine learning with Python, using Python data science tools and the scikit-learn machine learning library to give you a hands-on introduction to machine learning analyses.
We will build, evaluate, compare, and tune predictive models. Along the way, we’ll learn about key concepts in machine learning including overfitting, resampling, and feature engineering. You will gain knowledge about good predictive modelling practices, as well as hands-on experience in applying them. This workshop assumes intermediate Python knowledge. We expect participants to have some exposure to basic statistical concepts, but NOT intermediate or expert familiarity with modelling or machine learning.  
When: 2-3 May, 9am-5pm 
Duration: 2 full-day sessions, in-person only

Demystifying statistical modelling

May 9 Hybrid workshops: in-person or zoom

Do you get confused about the differences between linear and logistic regression or ANOVA, ANCOVA, repeated measures and mixed models? On May 9 we will deliver three workshops from our modular statistical training system to demystify these terms and show how all of these align in the one Linear Models framework
Linear Models Module 1 explains how the common analyses of regression, ANOVA, ANCOVA and repeated measures can all be done using the same Linear Models workflow. Module 2 then extends this to the Generalised Linear Model (GLM) framework for non-normal distributions such as Logistic and Count/Poisson regression. Aligning all these different methods into the same box with the same generic workflow makes it much easier to understand and remember how to apply them, while the practical examples provided give clear instructions for later use. The final module on the day, Statistical Model Building, explores the issues around more complex statistical modelling to build multivariable models with many predictors.

Bioinformatics workshop: running and customising nf-core workflows 

18 & 19 May, online 

Join SIH bioinformaticians for an online workshop over two sessions (18-19th May) to learn about running and customising Nextflow workflows developed by the nf-core community. nf-core is a community-driven effort to provide high-quality bioinformatics workflows for common analyses including, RNAseq, mapping, variant calling, and single cell transcriptomics. A big advantage of using nf-core workflows is the ability to customise and optimise them for different computational environments, types and sizes of data and research goals.  
This workshop will set you up with the foundational knowledge required to run and customise nf-core workflows in a reproducible manner. On day 1 you will learn about the nf-core tools utility, and step through the code structure of nf-core workflows. Then on day 2, using the nf-core/rnaseq workflow as an example, you will explore the various ways to adjust the workflow parameters, customise processes, and configure the workflow for your computational environment. 
This workshop is free, but participation is subject to application with selection. Applications close at 11:59pm AEST, Thursday 4 May 2023. See here for more details and to apply.  
When: 18-19 May  
Duration: 2 x 3h sessions - online
