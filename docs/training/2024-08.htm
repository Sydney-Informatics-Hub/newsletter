Hacky Hour

Demystifying statistical modelling    

26 August Hybrid workshops: in-person or Zoom

Do you get confused about the differences between linear and logistic regression or ANOVA, ANCOVA, repeated measures and mixed models? On August 26 we will deliver three workshops from our modular statistical training system to demystify these terms and show how all of these align in the one Linear Models framework.
Linear Models Module 1 explains how the common analyses of regression, ANOVA, ANCOVA and repeated measures can all be done using the same Linear Models workflow.
Module 2 then extends this to the Generalised Linear Model (GLM) framework for non-normal distributions such as Logistic and Count/Poisson regression. Aligning all these different methods into the same box with the same generic workflow makes it much easier to understand and remember how to apply them, while the practical examples provided give clear instructions for later use.
The final module on the day, Statistical Model Building, explores the issues around more complex statistical modelling to build multivariable models with many predictors.

Hello Nextflow! workshop

24 & 25 September, 2-5pm: Zoom 

Nextflow is a popular bioinformatics workflow orchestrator that makes it easy to run data-intensive computational pipelines. It enables scalable and reproducible scientific workflows using software containers on any infrastructure. SIH has been using Nextflow for the last few years to build scalable pipelines for national HPCs and is a member of the Nextflow Ambassador Community. And now, we’re delivering a workshop introducing you to the core concepts in partnership with Nextflow developers, Seqera. 
This workshop will put you on the path to writing your own workflows using Nextflow. You will learn how to use core components to build, run, and troubleshoot a scalable and multi-step workflow.
Join us on 24 & 25 September, 2-5pm AEST. The workshop is free to attend but applications are essential. See the Australian BioCommons website for more details.
