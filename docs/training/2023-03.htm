Hacky Hour is a regular meetup where all researchers – students, staff, and university affiliates – gather in a social environment to collaborate and receive research support. Experts and mentors from Sydney Informatics Hub and across the University will be available to advise and answer questions on coding, data analytics, or digital tools.
Come along and bring your stats, coding, and data science problems for us to solve! See you there. 

SIH Masterclass: Data Science with Orange: Machine Learning made easy

23 March, 3-4pm, online

Join us and learn how to develop powerful machine learning models without any coding skills using Orange, an open-source data mining software with an intuitive graphical interface. You will learn how to perform exploratory data analysis, visualize complex data, and build and evaluate predictive models without writing a single line of code. Whether you're new to the field or looking to expand your skills, we will provide you with a step-by-step introduction to how to build your machine learning model and the benefits of using Orange.

SIH Workshop: Introduction to Machine Learning with R and Tidymodels

28-29 March, 9am-5pm

This workshop introduces machine learning with R using the tidymodels framework, a collection of packages for modeling and machine learning using tidyverse principles. 
We will build, evaluate, compare, and tune predictive models. Along the way, we’ll learn about key concepts in machine learning including overfitting, resampling, and feature engineering.
You will gain knowledge about good predictive modeling practices, as well as hands-on experience using tidymodels packages like parsnip, rsample, recipes, yardstick, tune, and workflows. Only supervised machine learning (classification and regression) will be covered.  
This work assumes intermediate R knowledge. We expect participants to have some exposure to basic statistical concepts, but NOT intermediate or expert familiarity with modeling or machine learning.
