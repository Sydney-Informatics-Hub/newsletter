September 2021
Dear Researchers,
Another month, more lockdown (sigh)... SIH training will someday go back to in-person, but for now we wanted to share some of our new "on-demand" materials, as well as upcoming Zoom-based training. We've also included upcoming training that isn't yet open for registration, so you can "save the date". Stay safe & well!

Research Technology Webinars Watch On-Demand

Anytime, anywhere

(with an internet connection)

We have recently started running and recording short 1-hour webinars around research technology and tools, which you can catch up on in your own time! This includes:
"Getting Started with Excel", in which we demonstrated how to manage, analyse and visualise research data in Microsoft Excel for beginners.
"Start Coding Without Hesitation: Programming Languages Showdown”, in which we provided a head-to-head comparison of Python, R, MATLAB, and Julia

"A showcase of Data Analysis in Python and R: A case study using COVID-19 data”, in which we demonstrated the use of both R and Python for an initial analysis of COVID-19 datasets.

"Thinking like a computer: The Fundamentals of Programming", in which we discussed the different ways that humans and computers approach and solve problems, and taught in a very basic way the foundational concepts found in every programming language.

"Survey Tools in Research: REDCap and Qualtrics”, in which we explored and compared two of the most widely used tools in electronic data collection and surveys.

"From PC to Cloud or High-Performance Computing”, in which we explored the differences between Cloud Computing and HPC, and provided an overview of pros and cons of moving from traditional desktop computing to Cloud or HPC infrastructure.
